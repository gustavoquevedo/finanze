# Finanzas y pisos

App personal de ingresos, gastos y rentabilidad de pisos alquilados. Ver [AGENTS.md](AGENTS.md).

```bash
npm install
npm run dev   # http://localhost:3000
npm test
```

Fase 1: los datos se guardan en `localStorage`. La primera vez se cargan datos de prueba ficticios; se pueden restaurar desde Inicio.
